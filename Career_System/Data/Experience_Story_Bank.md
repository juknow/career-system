## EXP-001-A — 데이터를 활용한 일본어 현지화
- **상태:** [확정 기반]. 일본 사용자는 전체 이용자의 약 **20%**, 국가별 이용자 규모는 **한국 다음 2위**로 사용자 직접 확인.
- **문제:** 출시 뒤 이용자 반응과 플레이 지표를 개선해야 했음.
- **확인된 행동:** 국가별 이용 데이터를 검토하고, 일본어 미지원 문제를 발견해 현지화를 제안. 한국어·영어 XML 및 세계관·캐릭터 맥락을 AI에 제공, 일본어 인력 휴먼 검수를 조합.
- **확인된 결과:** 현지화 작업 단축과 패치 전후 사용 지표 개선. 정확한 기간·지표 정의·비교치는 Master §6.1 및 Metrics Bank만 참조.

- **문항 검색 키워드:** 문제해결, DX/AX, 데이터 활용, 제한된 자원, 실행.

- **확인 상태:** 현재 코드에서 **7개 평가 차원**의 독립 필드가 확인됐다. 외부 실사용자는 없는 개인 프로젝트이며, 외부 사용자 기반 학습 효과를 실적처럼 주장하지 않는다.
- **관련 과거 글:** KB26-Q2, KIA26-Q2, MOBIS26-Q2, HD26-Q4, LGU26-S2, CJ26-Q1, DBINC26-Q3, DBINC26-Q4.
- **출처 주의:** DBINC26-Q3·Q4는 미제출 작성본이며 두 문항의 본문이 동일하므로 별개의 수행 경험이나 검증 사례로 중복 계산하지 않는다.

## EXP-006-B — 전사 오류와 의미 피드백 오류를 구분한 검증
- **상태:** [확정 기반].
- **문제:** 전사 오류와 시험 맥락을 반영하지 못한 의미 피드백 오류를 같은 문제로 취급하면 원인을 분리하기 어려웠음.
- **본인 행동:** **gold transcript를 직접 제작**하고 로컬 모델, LLM 기반 평가 흐름, 유료 STT 모델을 포함한 여러 모델/구성을 실제로 비교해 전사와 평가 품질을 검증.
- **검증 구조:** WER와 substitution/deletion/insertion, filler retention, 반복 보존 등 전사 오류를 나눠 보는 평가 로직을 사용하고, 의미 피드백 문제는 별도 평가 흐름으로 분리.
- **구분:** `EXP-006-A`는 서비스 아키텍처의 역할 분리, 이 카드는 **실제 품질 문제 진단·비교 실험**에 초점을 둔다.
- **출처:** LGU26-S2 + 현재 저장소 + 2026-10-06 사용자 직접 확인.
- **경계:** 정확한 gold transcript 수, 사용 모델명, 모델별 수치·우열은 별도 확인 전 추가하지 않는다.

## EXP-006-C — AI Provider와 외부 의존성을 교체 가능한 구조로 분리
- **상태:** [확정 기반 — Repository].
- **문제:** 음성 전사와 평가 기능이 특정 외부 AI 서비스에 강하게 결합되면 모델 교체, 로컬 실행, 테스트 및 장애 대응이 어려워질 수 있음.
- **본인 행동:** OpenAI 기반 구현과 Ollama·faster-whisper 기반 로컬 구현을 Provider 단위로 분리하고, 전사·평가의 상위 입출력 구조는 유지하도록 설계. 외부 AI 호출은 자동 테스트에서 mock 처리하고 provider unavailable·timeout·invalid response 등 외부 의존성 실패를 별도로 처리.
- **확인된 구조:** OpenAI API variant와 Local LLM/STT variant가 존재하며 Provider abstraction, structured output, retry/timeout 및 요청 메타데이터 처리 구조가 저장소에서 확인됨.
- **구분:** `EXP-006-A`는 **STT·정량 지표·LLM 의미 평가라는 평가 책임의 분리**, `EXP-006-B`는 **전사 오류와 의미 피드백 오류를 진단·검증한 과정**, 이 카드는 **외부 AI 구현체의 교체 가능성과 테스트 가능성을 확보한 소프트웨어 구조 설계**에 초점을 둔다.
- **문항 검색 키워드:** 소프트웨어 설계, 유지보수성, 추상화, AI 엔지니어링, 장애 대응, 테스트, 외부 의존성 관리.
- **관련 과거 글:** DBINC26-Q3, DBINC26-Q4. 기아 지원서 활동란 및 Master §6.6에도 Provider 분리 구조가 기록됨.
- **주의:** 특정 모델 간 품질 우열이나 비용 절감 성과를 별도 측정한 것으로 확대하지 않는다.
