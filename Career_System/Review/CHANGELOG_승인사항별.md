# Career System v1.4 — 실제 적용 변경 명세서

**기준:** `Career_System_Separated_v1.4_REVIEW` 역할 분리 v1.4. 사용자가 이 버전을 기준으로 선택했으며, S-02(프로필 정리)·S-03(기존 5개 단계 보존)·S-04(선택 지원 가치 및 중복지원)·S-05(별도 갱신 프롬프트 2개 제거), 공통 규칙, Story Bank 동결, 간단한 문항별 배정표만 유지하도록 승인함.

**범위 유의:** 실제 파일을 **새 폴더에 생성**했으며 ChatGPT 프로젝트의 기존 파일이나 외부 저장소를 자동 덮어쓰지 않았다. 변경 중 사용자 미승인 사실 정정이나 신규 경험 확정은 없다. 기술 저장소는 이번 작업에서 다시 조사하지 않았다.

## C. Experience Story Bank
- **기존 파일 내용 그대로 복사**하고 `READ_ONLY` 파일명으로만 보존. 해당 파일 첫 줄의 '검토본' 표기는 원본 당시 메타데이터이며 이번에 새 사실로 승인하거나 갱신했다는 뜻이 아니다.
- 자동 등록/갱신 기능·별도 갱신 프롬프트를 추가하지 않는다.

**원본 보존에 관한 투명성:** 이전 채팅에서 사용자가 붙여 넣은 **원본 프롬프트의 핵심 분석 절차·목차·출력 목적**을 유지하도록 새 실행본을 작성했다. 문장 전부를 바이트 단위로 복제한 원본 파일은 아니며 중복되는 설명은 편집·축약했다. 기존 채팅에 붙여 넣었던 문장은 원본 참조 자료로 별도 보관해야 한다. 원문과의 축약 없이 1:1 본문을 요구할 경우 기존 본문에 변경 패치만 붙이는 방식으로 추가 작업이 필요하다.

## E. 시스템 운영·사용 가이드
- 신규 `Career_System_Common_Rules.md`: 사전 분석→질문/제안→사용자 승인→승인 범위 수행→차이 보고.
- `Career_System_사용_가이드.md`: 복잡한 3개 데이터 파일 필수 구성을 제거하고 **Master+Writing KB 2개 공통 파일**, 동결 Story Bank/원문 Archive 선택 자료로 설명.
- 독립 경험갱신·과거 자소서 등록 전용 실행 프롬프트 **패키지에서 제외**. 등록 요청이 발생하면 공통 승인 절차를 따른다.
- 문항 배정표를 해당 채팅에서 전달하며 별도 Story Map/Application Context 파일 생성은 기본값에서 제외.

## F. 승인 범위 밖으로 남긴 사항
- Story Bank 통합 여부는 **보류**: 합치거나 삭제하지 않았음.
- GS·KT·LIG 등 과거 자료에서 현재 미확인인 새로운 행동·수치·인과관계를 Master로 올리지 않았음.
- 일본 이용자 정확한 국가 순위·전자투표 정확한 추가 연장기간 등은 Verification Queue를 따름.
- 실제 프로젝트/ChatGPT 프로젝트에 최신 파일을 등록·교체하는 작업은 사용자 별도 확인이 필요함.
