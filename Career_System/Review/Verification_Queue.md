## 운영
- 새로운 증거가 생기면 `제안 내용 / 현재값 / 출처 / 영향받는 파일 / 사용자 승인 여부`를 먼저 적는다.
- 검토만 했거나 사용자가 승인하지 않은 사항을 `[확정]`이라고 표기하지 않는다.
- 기업별 자기소개서 초안에 영향을 주는 보류 항목은 사용자에게 먼저 질문하거나 해당 주장 없이 작성한다.
