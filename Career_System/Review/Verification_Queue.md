# Verification Queue v1.1 — 사용자 승인 갱신본

> 검토 기준: Career Master Profile v1.5, Writing KB v0.5, Experience Story Bank v1.1, 확인 가능한 2026 지원서 원문과 GitHub OpenCoachAI 공개 코드. 검토일: 2026-09-29.
>
> **상태 구분:** `해결`은 해당 쟁점이 확인됐다는 뜻, `원문 확인·재사용 주의`는 과거 서술의 존재만 확인됐다는 뜻, `부분 확인`은 코드 등 일부 근거만 있는 상태, `확인 필요`는 객관적 근거/사용자 답변이 추가로 필요한 상태.
>
> **중요:** 과거 지원서에 적혔다는 사실을 현재 경력 사실로 자동 승격하지 않는다. 이 파일의 승인·갱신은 Master·Story Bank·KB 본문의 수정을 의미하지 않는다. 필요한 다른 파일 변경은 각각 별도 승인을 받는다.

## 3. 반영 규칙

1. 해결된 사실도 기존 지원서 원문을 소급 수정하지 않는다.
2. 직접 사용자 확인이나 실제 코드·운영 자료 검증이 끝나면 상태·출처·확인일을 갱신한다.
3. 다른 MD 파일에서 '[미확인]'을 '[확정]'으로 바꾸어야 한다면 해당 파일별 변경안을 따로 제시하고 승인받는다.
4. 상태가 미해결인 객관적 역할·일자·수치·기술 상세는 신규 지원서에 확정 사실처럼 사용하지 않는다.
