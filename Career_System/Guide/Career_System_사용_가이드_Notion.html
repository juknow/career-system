커리어 시스템 사용 가이드

이 시스템은 실제 경력 정보와 과거 자기소개서 자료를 활용해, 기업 조사부터 최종 자기소개서 검토까지 이어서 작업하는 데 사용합니다.

1. 시작 전 준비

먼저 ChatGPT 취업 준비 프로젝트에 아래 세 파일을 등록합니다.

  1. Career System Common Rules — 중요한 판단이나 변경 사항을 최종 반영하기 전에 사용자에게 확인하는 규칙
  2. Career Master Profile — 학력, 프로젝트, 기술, 개인 기여, 확인된 성과와 커리어 선호에 관한 사실
  3. Personal Writing Knowledge Base — 기존 자소서 문항과 재사용 가능한 생각, 관점, 문체를 찾는 자료

과거 자소서 원문은 별도 보관합니다. 필요한 글이 검색됐을 때 해당 PDF 또는 원문 파일을 채팅에 제공합니다. Experience Story Bank는 과거 사건의 세부 내용이 필요할 때만 참고하며 별도로 갱신하지 않습니다.

2. 기업별 실제 사용 순서

1단계. 프로필 로딩

실행 파일: 01_Career_Profile_로딩.md

새 기업의 지원 작업을 시작할 때 이 프롬프트를 실행합니다. 공통 규칙, Master Profile, Writing Knowledge Base를 함께 제공합니다.

확인할 결과: 읽은 자료, 현재 커리어 선호, 중요한 미확인 정보. 이 단계에서는 기업이나 직무를 아직 선정하지 않습니다.

선택 단계. 지원 가치 및 중복지원 확인

실행 파일: 02_지원가치_판단_중복지원_선택.md

지원할지 고민되는 회사이거나 같은 그룹의 여러 공고에 지원하려는 경우에만 실행합니다. 회사명, 현재 채용공고 URL, JD, 이미 지원 중인 공고가 있다면 그 정보도 입력합니다.

확인할 결과: 지원 가능 요건, 회사와 직무의 특성, 지원 준비에 드는 시간, 공식 중복지원 규정, 전형 일정 충돌. 규정이 불명확하면 채용 담당자에게 확인할 사항을 남깁니다.

2단계. 최종 지원 직무 선정

실행 파일: 03_최종_직무_선정.md

회사 공고와 모집 직무를 입력합니다. 선택 단계의 조사 결과가 있으면 함께 전달하고, 없으면 바로 진행합니다.

확인할 결과: 각 직무의 실제 업무, 관련 경험과 부족한 근거, 근무환경, 장기 경력 경로. 비교 결과를 검토한 뒤 지원할 직무를 직접 확정합니다.

3단계. 지원서 전체 전략

실행 파일: 04_지원서_전체_전략.md

확정한 직무와 지원서의 모든 입력 항목·자소서 질문·글자 수를 원문 그대로 입력합니다.

확인할 결과: 프로젝트·활동 입력 방향과 간단한 문항별 경험 배정표. 경험이 적절한지 검토하고 승인합니다. 별도의 Story Map 파일은 만들지 않습니다.

4단계. 자기소개서 문항별 작성

실행 파일: 05_자소서_단일_문항_작성.md

문항마다 새 채팅을 열어 질문 원문, 글자 수, 승인한 경험 배정표의 해당 행을 제공합니다. 공통 세 파일을 읽을 수 없는 채팅이라면 다시 첨부합니다.

과거 관련 답변이 Writing Knowledge Base에서 발견됐다면 그 답변의 원문도 함께 제공합니다. 과거의 좋은 관점만 참고하고 이전 회사의 지원동기나 확인되지 않은 사실은 옮기지 않습니다.

확인할 결과: 문항 분석 → 필요한 질문과 작성 방향 확인 → 제출 가능한 초안. 중요한 소재 변경이 제안되면 먼저 결정합니다.

5단계. 지원서 전체 QA

실행 파일: 06_지원서_전체_QA.md

모든 문항의 최종안과 지원서 전체 입력 내용, 확정 직무, 문항별 경험 배정표를 한 채팅에 모읍니다.

확인할 결과: 사실·수치 오류, 경험 중복, JD와의 연결, 과거 회사용 표현, 예상 면접 질문. 수정 제안을 확인한 후 승인한 내용만 실제 지원서에 반영합니다.

3. 새로운 지원서를 다음 지원에 활용하기

완성한 지원서의 질문과 답변을 원문 그대로 보관합니다. 필요한 경우 다음 요청문을 별도 채팅에서 사용합니다.

첨부한 지원서의 질문과 답변을 원문 그대로 보관할 수 있도록 정리해 줘. Writing Knowledge Base와 비교해 새롭게 등록할 만한 문항과 인사이트만 먼저 제안하고, 내가 승인한 항목만 파일에 반영해 줘. 새로운 경력 사실이 발견되면 Master Profile 수정안을 별도로 제시해 줘. Experience Story Bank는 수정하지 마.

기존 자기소개서 등록이나 경험 갱신을 위해 별도의 전용 프롬프트를 실행할 필요는 없습니다.

4. 각 파일은 언제 열까?

자료사용할 때
Common Rules모든 작업에서 적용
Master Profile지원자 사실을 확인하는 모든 작업
Writing Knowledge Base과거 자소서 관점을 찾을 때
과거 자소서 원문관련 문항의 실제 문장을 확인할 때
Experience Story Bank기존 사건의 세부 기록을 참고할 때만
Review 폴더문서 변경 내용이나 사실 충돌을 확인할 때만

5. 작업 중 새로운 제안이나 오류가 발견되면

AI는 중요한 변경을 바로 확정하지 않고 먼저 변경 대상과 이유, 선택지를 제시합니다. 사용자는 각 항목을 승인·수정·보류할 수 있습니다. AI는 승인한 범위에서만 진행하고, 파일 변경 내역은 별도의 Review 자료에 정리합니다.

6. 이 가이드를 Notion에 넣는 방법

  1. Notion 웹 또는 데스크톱 앱에서 워크스페이스를 엽니다.
  2. 왼쪽 설정에서 가져오기(Import) → HTML을 선택합니다.
  3. Career_System_사용_가이드_Notion.html 파일을 선택합니다.
  4. 생성된 페이지의 제목과 단계가 잘 들어왔는지 확인하고 원하는 위치로 이동합니다.

Notion에 가져온 뒤에는 각 단계에 실제 프롬프트 파일 링크를 붙여 두면 편리합니다.
